# SmartPhysio
### An Intelligent IoT-Based Physiotherapy Rehabilitation Platform

Version: 1.0 (MVP)

---

# 1. Project Overview

## Introduction

SmartPhysio is an intelligent physiotherapy rehabilitation platform that combines wearable IoT hardware with a modern web application to assist patients in performing rehabilitation exercises accurately from home.

The system consists of an ESP32-powered wearable rehabilitation sleeve equipped with multiple sensors that continuously monitor arm movement, finger bending, wrist rotation, shoulder movement, and grip pressure. Sensor data is transmitted in real time to a web application where patients receive live exercise guidance, posture correction, movement visualization, and recovery analytics.

The objective is to bridge the gap between hospital-based physiotherapy sessions and home rehabilitation by providing continuous exercise monitoring without requiring constant physiotherapist supervision.

# 3. Problem Statement

Physiotherapy requires patients to perform rehabilitation exercises with proper posture, controlled movements, and consistent repetition.

Many patients perform these exercises at home without supervision, leading to:

- Incorrect exercise posture
- Improper movement angles
- Inconsistent exercise routines
- Reduced recovery effectiveness
- Increased risk of further injury
- Frequent hospital visits for monitoring

Existing rehabilitation methods rely primarily on physiotherapist observation, occasional follow-up visits, or instructional videos, none of which can verify whether the exercises are actually being performed correctly.

There is a need for an affordable intelligent rehabilitation platform capable of monitoring exercises in real time and providing immediate corrective feedback.
