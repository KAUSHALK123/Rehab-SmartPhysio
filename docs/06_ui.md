# SmartPhysio
# UI & UX Blueprint

Version: 1.0 (MVP)

---

# 1. UI Philosophy

SmartPhysio should provide a clean, modern, and distraction-free interface suitable for patients of all ages, especially elderly users.

The design should emphasize simplicity, readability, and real-time feedback while minimizing unnecessary interactions.

Core principles:

- Minimal UI
- Large buttons
- Easy navigation
- Real-time updates
- Responsive on mobile and desktop
- Accessibility-first
- Professional healthcare appearance

# 8. UI Design Prompt (For AI Design Tools)

Use the following prompt when generating the final UI in Figma AI, Stitch, v0, Lovable, Bolt, or any AI design tool.

---

## Master UI Prompt

Design a modern healthcare web application called **SmartPhysio**, an intelligent IoT-powered physiotherapy rehabilitation platform.

The application should feel premium, clean, trustworthy, and minimal, following modern SaaS dashboard principles while remaining friendly for elderly users.

### Design Style

- Modern Healthcare Dashboard
- Minimalistic
- Soft rounded corners (12–16px)
- Glassmorphism only where appropriate
- Clean spacing
- Professional typography
- Smooth micro animations
- Responsive for desktop and mobile
- Light mode (primary)
- Dark mode ready

### Color Palette

Primary:
- Medical Blue

Secondary:
- Emerald Green

Accent:
- Cyan

Success:
- Green

Warning:
- Orange

Error:
- Red

Background:
- Soft White (#F8FAFC)

Cards:
- White
